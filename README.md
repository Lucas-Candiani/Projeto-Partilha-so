# Projeto-Partilha-so
Projeto desenvolvido durante a disciplina de Projeto Integrar II

O Projeto Partilhaíso Doações consiste na criação de um site / sistema web que funcionará como um centralizador de instituições benificentes.

Após finalizar uma grande faxina em casa e remover roupas e sapatos do guarda-roupas que já não servem mais, você já ficou em dúvida "Para quem eu poderia doar isto tudo?" ?
Para solucionar exatamente esse problema desenvolvemos o Partilhaíso. Nosso objetivo é que grande parte das instituições benificentes de São Sebastião do Paraíso se cadastrem em nossa plataforma e que ela fique muito conhecida entre a população. Assim, quando alguém precisar fazer uma doação, saberá exatamente onde procurar.

As instituições terão um perfil onde adicionarão quais itens estão em falta e quais tipos de recursos aceitam como doação, informações importantes como o endereço, chave pix segura para receberem doações etc.
O usuário convencional poderá seguir instituições, acompanhar suas publicações para verificar se sua doação realmente está chegando ao público-alvo, se inscrever como voluntário para instituições que necessitem dessa ajuda e conversar através de um site com os responsáveis pelas organizações.
